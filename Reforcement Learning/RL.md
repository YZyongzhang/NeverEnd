# RL 
## 如何理解RL
1. 强化学习是属于机器学习中的一种，这里主要聚焦于强化学习的基本理念。稍微如果聊解过强化学习，那么就可以知道强化学习就是和环境相互作用的过程中，通过环境的反馈来进行学习的过程，这一点和人类很相似。

2. 那么强化学习是通过什么来完成这个学习过程的呢？通过奖励，这个奖励就是环境的反馈，类比于人类我们可以理解为多巴胺。当agent也就是我们想要训练的model，和环境进行交互的时候，如果它这个工作完成的好，那么环境就会给一个正值的奖励，反之负值。

3. 强化学习的核心有两个概念，一个是状态价值，一个是动作价值。当然，如果我们在这里直接谈论这两个价值的话，我们当然是很难理解的，因为这两个概念是定义在马尔可夫决策过程中的。
